# Life Progress Android Updates

Public APK downloads for Life Progress. This repository contains installation instructions and release packages; application source code is maintained privately.

## Install

Open [Releases](https://github.com/Tatar3n/AdvanceDreamTracker-updates/releases) and download the `LifeProgress-<version>-android.apk` asset. Android 7 or later is required. `SHA256SUMS` contains the checksum. GitHub's automatically generated source archives contain this distribution README, not the Android app.

Install the APK over your existing Life Progress installation. Keep the existing app installed to preserve its data. The 0.3.0 package uses the same signing certificate as 0.2.0.

## Later Updates

Starting with 0.3.0, open **More → Проверить обновления** inside the app, download the offered version and choose **Установить обновление**. Allow Life Progress to install updates in Android settings if prompted, return to the app, then confirm the system installer. This prototype includes prereleases when checking updates.

The first version with the updater must be installed manually. Updates are user-initiated; no GitHub account is required. APKs use the prototype signing configuration for manual installation. Android installer behavior still needs verification on the user's phone.
